# UI/UX Design Brief - NetChat

## 1. Design Philosophy
Clean, functional, and distraction-free. The interface prioritizes readability and rapid navigation between chat contexts.

## 2. Layout Structure
- **Sidebar (Left)**:
    - User Profile (Current Username).
    - Online Users List (Scrollable).
    - Group List (My Groups vs All Groups).
- **Main Chat Area (Center)**:
    - Header: Room Name (e.g., "Public Chat" or "#PythonDevs").
    - Message Log: Scrollable area with timestamped messages.
    - Input Field: Text box for typing messages.
    - Send Button: Action trigger.
- **Control Panel (Right/Top)**:
    - Login/Register toggle.
    - Group Management (Create/Join).

## 3. User Experience (UX) Patterns
- **Context Switching**: Clicking a user in the sidebar instantly switches the Main Chat Area to a Private Conversation.
- **Visual Feedback**: 
    - Error messages displayed via pop-up alerts or a status bar.
    - "User Joined/Left" system messages in the chat log.
- **Input Handling**: `Enter` key triggers the "Send" action.

## 4. Color Palette (Suggested)
- **Background**: Light Gray / Dark Slate.
- **Text**: Charcoal / Off-white.
- **Accent**: Primary Blue (for buttons and active selections).
